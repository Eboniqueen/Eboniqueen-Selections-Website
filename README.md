# Eboniqueen Selections Website

A mobile-friendly HTML/CSS/JavaScript starter website for Eboniqueen Selections.

## Before publishing
1. Replace the bank placeholders in `index.html`.
2. Replace the WhatsApp number in the `wa.me` link.
3. Replace/add your real product images when ready.
4. Update product prices and descriptions as needed.
5. Create a GitHub repository and upload these three files.
6. Enable GitHub Pages from the repository settings.

## Security
Never put online-banking passwords, PINs, OTPs, API keys, or other private credentials in the website code.
